# Kalimenu: λίστα ελέγχου για το launch

> Δεν είναι νομική ή φορολογική συμβουλή. Τα σημεία με ⚖️ θέλουν έλεγχο από **λογιστή** ή **δικηγόρο**. Πάρτε αυτή τη λίστα μαζί σας
> στη συνάντηση.

Κάθε σημείο έχει μία από τρεις καταστάσεις:
- **✅ Έτοιμο:** υπάρχει ήδη στην εφαρμογή.
- **🟡 Εσείς:** το κάνετε εσείς.
- **⚖️ Επαγγελματίας:** χρειάζεται λογιστή ή δικηγόρο.

---

## 1. Επιχείρηση και φορολογικά (πριν την πρώτη πληρωμή)

| # | Τι | Κατάσταση |
|---|---|---|
| 1.1 | **Έναρξη δραστηριότητας** στην ΑΑΔΕ: ατομική επιχείρηση ή εταιρεία (π.χ. ΙΚΕ). Ο λογιστής επιλέγει τον σωστό **ΚΑΔ** για παροχή λογισμικού ως υπηρεσία (SaaS) | ⚖️ |
| 1.2 | Εγγραφή στο **ΓΕΜΗ** και στον **e-ΕΦΚΑ** | ⚖️ |
| 1.3 | **Επαγγελματικός λογαριασμός τράπεζας** (IBAN για τις εκκαθαρίσεις της Stripe) | 🟡 |
| 1.4 | **Τιμολόγηση των συνδρομών στο myDATA.** Κάθε πληρωμή μέσω Stripe θέλει δικό σας παραστατικό (τιμολόγιο παροχής υπηρεσιών). Η απόδειξη της Stripe δεν αρκεί. Επιλέξτε με τον λογιστή πάροχο ηλεκτρονικής τιμολόγησης. Έχει ξεκινήσει σταδιακά η υποχρεωτική ηλεκτρονική τιμολόγηση B2B, οπότε ρωτήστε ποια ημερομηνία ισχύει για εσάς | ⚖️ |
| 1.5 | **ΦΠΑ:** 24% σε Έλληνες πελάτες. Σε επιχειρήσεις άλλων χωρών της ΕΕ με έγκυρο ΑΦΜ στο VIES εφαρμόζεται αντίστροφη χρέωση. Οι τιμές στο site αναγράφονται «χωρίς ΦΠΑ». Αυτό επιτρέπεται επειδή πουλάτε μόνο σε επιχειρήσεις | ⚖️ |
| 1.6 | **Stripe** με τα στοιχεία της επιχείρησης (ΑΦΜ, IBAN). Τα κλειδιά `STRIPE_SECRET_KEY` και `STRIPE_WEBHOOK_SECRET` στο Render (βλ. [README](../README.md#ανέβασμα-online-βήμα-βήμα)) | 🟡 |

| # | Τι | Κατάσταση |
|---|---|---|
| 3.1 | Εφαρμογή στο Render, βάση στο Neon | ✅ |

| 3.3 | **Render Starter ($7/μήνα)** πριν τον πρώτο πραγματικό πελάτη. Μέχρι τότε UptimeRobot κάθε 5 λεπτά στο `/healthz` | 🟡 |
| 3.4 | **Super admin:** `SUPERADMIN_EMAIL` και `SUPERADMIN_PASSWORD` στο Render. Δοκιμή σύνδεσης στο `/super` | 🟡 |
| 3.4α | **Διεύθυνση ανά κατάστημα:** `*.kalimenu.gr` στο Render → Custom Domains, εγγραφές DNS στο Papaki, αναμονή για «Verified», και μετά `BASE_DOMAIN=kalimenu.gr`. Δοκιμή με το `demo.kalimenu.gr` | 🟡 |
| 3.4β | **kalimenu.com (ΗΠΑ):** `kalimenu.com` και `www.kalimenu.com` στο Render → Custom Domains, `US_APP_URL=https://kalimenu.com`, και για διεύθυνση ανά κατάστημα `*.kalimenu.com` με `US_BASE_DOMAIN=kalimenu.com`. Δοκιμή με το `demo-us` | 🟡 |
| 3.4γ | **ΗΠΑ, νομικά και φόροι:** έλεγχος των αγγλικών όρων από δικηγόρο στις ΗΠΑ, εγγραφή για sales tax στη Νέα Υόρκη (SaaS) και Stripe Tax. Ρωτήστε αν χρειάζεται εταιρεία στις ΗΠΑ | ⚖️ |
| 3.4δ | **Cookies και διαφημίσεις:** αν τρέχετε διαφημίσεις στο Meta, ορίστε `META_PIXEL_ID` (και `GA_MEASUREMENT_ID` για Google Analytics). Το μήνυμα συγκατάθεσης εμφανίζεται μόνο του | 🟡 |
| 3.5 | **Stripe σε test mode πρώτα:** κάρτα δοκιμής `4242 4242 4242 4242` → επιλογή πλάνου → webhook → η συνδρομή γίνεται «Ενεργή» → portal → ακύρωση. Μετά περνάτε στα live κλειδιά | 🟡 |
| 3.6 | **Stripe customer portal:** Settings → Billing → Customer portal → Save | 🟡 |
| 3.7 | **E-mail (Resend):** επιβεβαίωση του kalimenu.gr με τις εγγραφές DNS που δίνει το Resend στο Papaki. Το Resend χρησιμοποιεί υποdomain (`send.kalimenu.gr`), οπότε δεν πειράζετε το υπάρχον SPF. Μετά ορίζετε `RESEND_API_KEY`. Δοκιμή με «Ξεχάσατε τον κωδικό;» | 🟡 |
| 3.8 | **Αντίγραφα ασφαλείας:** το Neon κρατά ιστορικό επαναφοράς, αλλά περιορισμένο στο δωρεάν πλάνο. Κατεβάζετε και ένα αντίγραφο την εβδομάδα (`pg_dump`), ή το αναβαθμίζετε όταν έρθουν πελάτες | 🟡 |
| 3.9 | **Διπλός έλεγχος ταυτότητας (2FA)** σε GitHub, Render, Neon, Stripe, Papaki και στο e-mail σας | 🟡 |
| 3.10 | **Δοκιμή σε πραγματικές συσκευές:** iPhone και Android με σκανάρισμα QR, οθόνη σερβιτόρου σε κινητό, κουζίνα σε tablet, εκτύπωση QR σε A4, θερμικός εκτυπωτής αν έχετε | 🟡 |
| 3.11 | **Κύριο branch:** το Render τρέχει τώρα από το `claude/eloquent-ride-1rvzxj`. Καλό είναι να γίνει merge στο `main` και το Render να γυρίσει σε αυτό | 🟡 |
| 3.12 | Headers ασφαλείας, HTTPS, κρυπτογραφημένοι κωδικοί, όρια προσπαθειών σύνδεσης, διαχωρισμός καταστημάτων (με tests) | ✅ |
